# Alladeen-GPT 🎯
Where every answer is wrong and every game is rigged.

### Project Description
AlladeenGPT is a deliberately useless AI chatbot that refuses to help, roasts you for asking, and loads forever on purpose. Inspired by Admiral General Aladeen from The Dictator (2012), it gives confidently wrong answers, mocks every question, and can even "leave" the conversation when annoyed. A sad plant will be seen in the page which will get dried out when you get roasted more times. Dictator games are present where only Aladeen wins.

### The Problem (that doesn't exist)
Modern AI assistants are too helpful. They answer politely, apologize for mistakes, and try their best to solve your problems. This is exhausting. What if your AI treated you like an annoying peasant who dared to speak?

### The Solution (that nobody asked for)
We built an AI that:
  Gives confidently wrong answers to every question.
  Roasts you personally based on what you ask.
  Loads forever with fake "Ministry of Truth" messages.
  Tracks a patience meter that drops with every message.
  Includes useless games (Dodge the dictator, Catch Aladeen) where Alladeen always wins.
  Displays a confidence meter that stays at 100% no matter how wrong the answer is.
  Has a "Fact-check" button that makes him double down instead of correcting himself.
  Gates the first message behind an impossible first try CAPTCHA, which lets you in after 1 try.
  It is a complete, polished, and aggressively useless product.

# Installation
 Clone the repository
  git clone https://github.com/Pranavcpradeep/useless_project_Kopiko.git
  cd useless_project_Kopiko
 Install dependencies
  npm install
 Create your .env file with:
 GROQ_API_KEY=your_groq_api_key_here
 DATABASE_URL=your_postgres_connection_string

# Run
 Development
  npm run dev
 Production build
  npm run build
  npm start
  Then open http://localhost:3000.
